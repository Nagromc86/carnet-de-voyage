# Carnet de voyage

Appli web installable (PWA) pour garder tout un voyage au même endroit, même hors ligne :
vols, logements, programme jour par jour, billets en PDF, carte avec temps de trajet, export PDF.

Les données (voyages, billets, photos) restent sur l'appareil. Ce dépôt ne contient que le code de l'appli.

Installation : ouvrir https://nagromc86.github.io/carnet-de-voyage/ dans Chrome, puis ⋮ › Installer l'application.
